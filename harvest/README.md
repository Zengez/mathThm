# Harvest working area

Accepted theorem records remain in data/theorems.json.

Candidate artifacts from a source harvest should be stored in a separate local
.harvest_runs/<batch-id>/ workspace or downloaded from the manual GitHub Actions
Pass 1 run. Do not commit raw/proof excerpts to the public theorem catalog.

The stable, minimal program contract and commands are in HARVEST_RUNBOOK.md.
Pass 3 needs-more-investigation outcomes must remain separate from provisional
published results. No full-proof audit is implied by plausible screening.

The first live Stacks Pass 1 run is an artifact-only smoke check of the
source adapter. It does not publish any theorem.
